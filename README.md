# Isaac Adegbite Portfolio

Personal portfolio site for Isaac Adegbite, Digital Marketer (Lagos).

A static site with no build step: `index.html` plus one image.

## Deploy on Vercel
1. Import this repository at vercel.com/new
2. Framework preset: **Other**. Leave the build command empty and the output directory as the root.
3. Deploy.

## Edit
All content and styles live in `index.html`. The portrait is `isaac-halftone.png`.
